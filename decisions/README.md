## 과정 요약

처음 출발점은 "경기 결과 스크린샷을 OCR로 읽어 티어표를 만든다"였다.
그런데 세이브 파일을 열어보니 게임이 이미 모든 것을 구조화해서 저장하고 있었고,
그 순간 프로젝트의 성격이 **수집 문제에서 분석 문제로** 바뀌었다.

이후 결정은 대부분 "게임이 이미 해주는 것"과 "게임이 못 하는 것"을 가르는 작업이었다.

```
OCR 전제 설계
   ↓ 세이브 파일이 평문 BinaryFormatter임을 확인
세이브 파싱으로 전환
   ↓ 4v4, 라인 없음, 역할군 5종 확인
스키마 전면 수정
   ↓ 세이브가 현재 시즌만 보관함을 확인
"시즌 누적"이 프로젝트의 핵심 가치가 됨
   ↓ 패치가 커리어마다 고유 생성됨을 확인
패치 처리를 챔피언 버전 기준으로 전환
   ↓ 효과 크기와 조합 집중도를 측정
표본 기준 10경기 + 축소추정 정렬로 확정
```
