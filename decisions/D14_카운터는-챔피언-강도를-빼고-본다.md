## D14. 카운터는 챔피언 강도를 빼고 본다

**문제.** raw 승률에는 챔피언 자체 강도가 섞여 있다. Werewolf 기저 승률이 61%라
raw 정렬로는 Werewolf 가 거의 모든 상대에서 상위를 차지한다. 그건 카운터표가 아니라
"센 챔피언 목록"이다.

**측정.** 카운터 승률 분산 분해 (n≥10, 1,204쌍).

| 출처 | 표준편차 | 분산 비중 |
|---|---|---|
| 챔피언 자체 강도 | 0.0525 | 19% |
| 페어 고유 상성 | 0.0197 | 3% |
| 순수 노이즈 | 0.1027 | 78% |

**결정.** Bradley-Terry 로 두 챔피언 기저 강도만으로 예측되는 승률을 구하고, 실제와의
차이를 상성 이득으로 본다.

```
expected(A,B) = p_A(1-p_B) / ( p_A(1-p_B) + p_B(1-p_A) )
counter_effect = adjusted(A,B) - expected(A,B)
```

정렬은 `counter_effect`, 화면에는 실제 승률·기대 승률·상성 이득을 함께 표시한다.
효과가 실제로 뒤집힌다:

```
raw 정렬:  Werewolf vs Swordman  84.0% (기대 66.6%, 이득 +17.4%p)
잔차 정렬: Fighter  vs DarkMage  76.0% (기대 42.8%, 이득 +33.2%p)
```

Fighter 는 전체 승률 42%인 약한 챔피언인데 DarkMage 상대로는 76%다. raw 정렬로는 안 보인다.

**주의.** 페어 고유 상성의 평균 크기는 2%p로 작다. 대부분의 매치업에는 상성이 없고,
소수가 +33%p로 튄다. 전체 매트릭스를 색칠하기보다 **유의한 쌍만 뽑아 보여주는 게 맞다.**

**챔피언 티어에는 보정하지 않는다.** 티어는 "이 챔피언이 센가"를 묻는 것이므로
기저 승률 자체가 답이다. 보정은 카운터·시너지에만 적용한다.
