## D21. 화면 구성은 lol.ps 를 차용하되 두 가지를 바꾼다

**구조.** `/tier` 티어표 → 챔피언 클릭 → `/champion/[code]` 상세(카운터·시너지).

**티어표 열 (전부 정렬 가능).** 티어 / 승률 / 픽률 / 밴률 / 경기 수 / 최근 변화 /
KDA·딜·탱·힐. 필터는 역할군 / 커리어(슬롯) / 패치 / 스크림 포함 / 기간.

**정렬 축에 따라 표본 기준이 달라진다.** 승률 정렬에서는 10경기 미만을 빼야 하지만,
픽률 정렬에서는 "픽률이 낮다"는 것 자체가 정보라 빼면 안 된다. UI 에 명시한다.

**lol.ps 에서 안 가져오는 것**

- 라인 탭 — 이 게임에 라인이 없다. 역할군 필터로 대체
- OP 스코어 같은 단일 종합 점수 — 진짜 효과 크기가 작아서 소수점까지 있는 점수는
  근거 없는 정밀도가 된다

**대신 추가하는 것**

- `/gaps` — 표본이 부족한 매치업과 "스크림 몇 판이면 판정 가능". 게임도 lol.ps 도
  못 하는 화면이고, 수동적 뷰어를 데이터 수집 도구로 바꾸는 지점이다
