## D3. 파서는 C# 대신 직접 구현

**상황.** `Scripts.dll` 을 참조하면 `BinaryFormatter.Deserialize()` 한 줄로 끝난다.

**근거.** 개발 PC에 .NET SDK가 없었다(Python 3.13, Node 24만 있음). 그리고 BinaryFormatter는
.NET 9에서 제거돼서 .NET Framework 4.8이나 .NET 8로 고정해야 한다. MS-NRBF 포맷은 문서화돼
있고, 실제로 파이썬 파서를 300줄로 구현해서 3슬롯 전부 파싱에 성공했다(0.39초).

**결정.** NRBF 파서를 직접 구현한다. 프로토타입은 Python(`tools/nrbf.py`), 제품은 TypeScript로 포팅.
게임 DLL에 의존하지 않으므로 배포도 자유롭다.

**뒤집힐 조건.** 포팅 비용이 예상보다 크면 Python 워커를 별도 프로세스로 두는 것도 가능하다.
