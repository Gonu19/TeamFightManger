## D15. 패치 가중치: 2단 축소 + 이중 감쇠

**문제.** 패치 구간으로 자르면 표본이 죽고(D7), 무시하면 부정확하다. 그리고 패치가
Werewolf 를 너프하면 **Werewolf 를 안 건드렸어도 Fighter 의 승률은 바뀐다.** 상대 풀이
달라지기 때문이다. 즉 안 바뀐 챔피언도 감쇠를 받아야 하는데, 그러면 남는 데이터가 없다.

**결정.** 세 가지를 동시에 쓴다. D7 의 버전 키 방식을 이것으로 대체한다.

**(a) 이중 감쇠 — 자기 변경은 세게, 메타 변화는 약하게**

```
w(g) = 0.5^(자기변경횟수 / 2)  ×  0.5^(경과패치수 / 12)
```

자기 변경은 1차 효과, 메타 변화는 2차 효과다. 반감기 12패치는 시즌 3~4개 분량이라
최근 시즌은 거의 안 깎이고 4시즌 전 데이터가 절반이 된다. 버전 키(hard cut)는
반감기 0인 극단, 무가중은 무한대인 극단이고 이건 그 사이를 연속적으로 움직인다.

**(b) 2단 축소 — 핵심**

패치별로 완전히 분리하지도, 완전히 합치지도 않는다. 각 패치의 추정치를
**그 쌍의 전체 누적 추정치** 쪽으로 당긴다.

```
1단 (전체 누적, 감쇠 적용, 기저값으로 축소)
  θ_all(A,B) = ( Σ w·win + k₀·expected(A,B) ) / ( Σ w + k₀ )     k₀ = 24

2단 (특정 패치, 전체 누적값으로 축소)
  θ_patch(A,B,p) = ( n_p·wr_p + k₁·θ_all(A,B) ) / ( n_p + k₁ )   k₁ = 15
```

데이터가 많은 패치는 자기 데이터가 지배하고, 적은 패치는 전체 누적값으로 수렴한다.
**패치 반영과 표본 부족을 동시에 푸는 유일한 구조다.**

축소 대상이 3단 계단을 이룬다: **패치 추정 → 전체 누적 추정 → 챔피언 강도 기대값.**
데이터가 없을수록 위로 올라가며 "모르면 아는 것에 가깝게" 답한다.

**(c) 경기력 지표로 정보량 보강** — D19 참조.

**저장.** 원시 카운트(`games`)와 가중 합계(`weighted_games`, `weighted_wins`)를 둘 다 둔다.
표본 기준(10경기) 판정과 화면 표시는 원시 카운트로, 승률과 정렬은 가중값으로.
유효표본수 `ess = (Σw)² / Σw²` 로 신뢰구간을 잡는다.

**뒤집힐 조건.** 반감기 2와 12는 측정으로 정한 값이 아니다. 패치 전후 승률 변화를
쌍 단위로 재려면 표본이 더 필요하다. `analysis_config` 에서 조정한다.
