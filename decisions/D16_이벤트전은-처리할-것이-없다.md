## D16. 이벤트전은 처리할 것이 없다

**확인한 것.** 이벤트전을 실제로 치르고 세이브를 다시 파싱했다.

```
이벤트 스케줄 ID109  Progress 0.0 → 1.0, 스코어 0:1
GameStat   294 → 294 (+0)
ScrimStat  180 → 180 (+0)
```

**이벤트전은 밴픽·챔피언·개인스탯을 저장하지 않는다.** 스케줄에 스코어만 남는다.

`EventMatchData = { Type, Category }` 이고 Category 가 `ChampionCategory` 이므로
역할군 제약이 걸리는 특수 룰 경기로 보인다. 정상 드래프트가 아니라 통계에 섞이면
곤란한데, 애초에 데이터가 안 남으니 **제외 로직도 `is_event` 컬럼도 필요 없다.**

**뒤집힐 조건.** 확인한 것은 `Type=7 / Category=0` 한 종류뿐이다. 다른 타입이 데이터를
남기면 그때 대응한다. 위험은 낮다 — 안 남기는 쪽이 기본 동작으로 보인다.
